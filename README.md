# Habeshan REMS - # Group 5 Project

Remote Employee Management System built for Ethiopian outsourcing agencies and distributed teams.

## Problem

Global remote-work tools (Hubstaff, Time Doctor, Deel) are priced in USD, assume reliable connectivity, and aren't built for how Ethiopian outsourcing agencies and dev shops actually operate. As a result, most teams fall back to Google Sheets, WhatsApp check-ins, and manual timesheets — with no reliable way to track attendance, tasks, or provide proof-of-work to international clients.

## Description

Habeshan REMS is a lightweight, ETB-priced platform for managing distributed teams: attendance tracking, task assignment, timesheet approval, and client-facing work reports — built with offline-first sync and Telegram notifications to fit local connectivity and communication habits.

## MVP Features

- **Attendance tracking** — clock-in/out with offline queue that syncs when connectivity returns
- **Task boards** — simple Kanban-style task assignment and status tracking per employee
- **Timesheet approval** — employee submits, manager approves/rejects, exportable for payroll/billing
- **Manager dashboard** — team-wide view of active employees, hours logged, task completion
- **Telegram bot integration** — check-in reminders and approval notifications
- **Role-based access** — admin, manager, and employee views
